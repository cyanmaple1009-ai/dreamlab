What Happens

假设你是一名梦境旅客，
你会经历什么？

现在躺在床上，闭上眼。一片黑暗——别担心，这是正常的。

你的意识渐渐模糊。当你进入浅睡期（light sleep），你的脑海中会浮现入睡前最后看到的场景，不清晰，但稳定。若你的视线范围内存在处于睡眠状态的生物，你能感知到其波动于其中产生、发散，依旧模糊、细微。

你并不了解该波纹之形态、频率或任何用于描述它的科学语言——不过研究人员会很在意。你只是静默，感受。

如果你再度闭上「眼」，放任思维发散或趋于空白，你会进入正常的睡眠周期。无需行动，仅需「想」。

你渐渐失去时间意识，直到对方波纹呈现低振幅快波特征，你的眼前渐渐出现色彩、声音，你再一次获得了身体的控制权。

恭喜你，潜入了对方的梦境。

潜入的三个条件

01

你与对方全部入睡

双方都必须处于睡眠状态，这是无法绕过的前提。

02

同一空间且未经遮挡

你与对方处于同一空间内且未经遮挡；或者，对方在研究所特制摄像头「另一只眼」的视线范围内。

03

你的能量值不为 0

能量值即为梦境中的心灵能量（PE）。能量归零者无法潜入，也会被强制弹出。

反过来说也一样成立

你可以尝试清醒梦——创造属于你的梦境，并邀请他人进入你的梦境中。这同样属于潜入行为，需要完成授权与登记。

Dream Mechanics

关于梦境的六条机制

这六条是《梦境解析导论》第一讲的全部内容，也是每一名潜梦员入梦前必须记住的东西。它们解释了梦为什么长这样。

一条容易被忽略的补充

梦境中，梦境主人的主视角不一定是梦境中的自己，第三人称视角是有可能的；同时，梦境主人所认知中的自己也未必与现实中等同。因此，判断「谁是梦境主人」往往比判断「梦境主人做了什么」更困难。

Parsing Principles

关于梦境的解析

梦境中的信息如同大数据：信息密度高，但是单位价值低。以下六条解析原则，是研究所用无数次误判换来的。

PR / 01

切忌利用单一信息进行分析

梦境主人所认为的自己的行为大概率反映其思维，但切忌忽略人的复杂性而分析其单一行为。孤证不立，在梦里的严格程度要高于现实。

第一铁律
PR / 02

出现，即意味着「知晓」

梦境中出现的人物或物品未必源于现实。但若梦境中出现现实中存在的人物与物品，梦境主人必然「知晓」此人或物。若其只是听说或浅显了解某事物，该事物可能以不同于现实中的情状出现。

推论基础
PR / 03

梦中的行为 ≠ 现实的态度

梦境中若出现现实中存在的人物，该人物的行为未必与现实中该人物相似，甚至未必与梦境主人对该人物的印象相似。

常见误判点
PR / 04

出现次数代表关注度

出现次数在一定程度上体现了梦境主人对此事物的关注度。同时数据显示：恐惧的事物相比于喜爱的事物会更易出现。所以梦里的高频道具，未必是 ta 喜欢的东西。

量化线索
PR / 05

新事物优先成像

短期内出现的新事物更易于在梦境中体现。刚发生的事，往往比十年前的旧事更容易在当晚的梦里找到痕迹。

时效性
PR / 06

引导是允许的，也是危险的

你可以尝试对梦境进行引导，利用梦境中放大的原理探索梦境主人的内心世界。但请注意：引导会改变被观测对象，「观测」与「干预」之间的界线，正是伦理与合规部存在的理由。

需授权
Diving Protocol

关于潜梦的规则

以下九条是现场作业时最常被引用的规则。请特别注意第 4 条：它决定了你有多少时间。

DP / 01

梦境主人可能提前醒来

当梦境主人于梦中受到过分惊吓或伤害，其可能提前从梦中醒来。

DP / 02

醒来后的记忆强度

梦境主人可能记起梦境中所发生事件。若其于快速眼动睡眠期因惊吓醒来，记忆会更加清晰。

DP / 03

避免惊扰是硬要求

为防止潜梦者被察觉，也为梦境主人提供优质的睡眠，请尽可能避免其受到惊吓或伤害，保护其不被惊醒。

DP / 04

40 分钟窗口

快速眼动睡眠期一次约持续 40 分钟。这意味着你要尽可能于 40 分钟内收集尽可能多的信息。

DP / 05

PE 归零即弹出

当你在梦境中受到伤害时，你的心灵能量会相应减少；当你的心灵能量归零时，你会从梦中被强制弹出。

DP / 06

异能仅存于梦中

梦境异能是仅能于梦境中使用的异能。梦境旅客往往拥有独特的梦境异能，同时也可以通过学习获得新的异能。

DP / 07

睡眠质量必然受损

若你选择潜入梦境，你的睡眠质量必然受到影响。这是选择潜梦的固定代价。

DP / 08

未经许可的潜梦不合法

未经本人或组织许可的潜梦是不合法的。这一条写在所有规范的最前面。

DP / 09

梦境主人可能夺取主导

梦境主人有小概率意识到梦境并进而主动掌控梦境。此时应立即中止观测。

心灵能量 PE 与防御等级 AC

Psyche Energy · PE 10 + 3n 量化你在梦境中对于伤害的承受力，类似血量。若 PE 耗尽，角色会被强制弹出梦境。n 为能量属性加值。
Armor Class · AC 10 + n 决定了敌人对你进行攻击检定时所需达到的点数。标准防御等级为 10，情绪加值每增/减 1 点，AC 随之增/减 1 点。
Two Names, One Meter PE 与「能量值」完全对应 在梦境中，你的能量值就是你的心灵能量值。你甚至可以认为这只是两个不同的称呼。现实中能量值减少后未经恢复进入梦境，梦中的 PE 同样保持该数值。
Recovery 不潜梦：完全恢复 / 潜梦：三分之一 心灵能量会随睡眠而恢复。当你不进行潜梦时，该晚心灵能量完全恢复；当你进行潜梦时，该晚心灵能量恢复总数的三分之一。研究所售卖的一些物品也可恢复心灵能量。

能量属性的消耗规则

能量是一项特殊的属性，代表角色的行动意愿——它不仅是「体力」的体现，更意味着一种「精神体力」。能量低意味着角色处于「疲劳」或「精力不足」的状态。

使用方式能量消耗说明
作为主要检定属性-3无论成败与否
作为次要检定属性-1无论成败与否
能量值归零时检定值 = 0所有能量检定值（无论主要次要）都将变为 0

什么时候会用到能量属性

当某行动明确需要长期坚持努力或需要消耗精力时（例如从江的一岸游到对岸、做完一张数学试卷）；当某行动难以找到两个以上的影响因素时；以及当某项次要检定属性恰是你不擅长的属性时，玩家可以主动选择用能量检定代替该次要检定。

Dream Abilities

梦境异能怎么设计

梦境异能是这个世界的少数人拥有的特殊能力，仅能在梦境中使用，可违背现实中的物理规律。每名梦境旅客都拥有专属的梦境异能，也能通过学习获得新的异能。

你有两个自定义机会

其中一个为攻击类招式，另一个为变化类招式。你可以自由地为招式起名、想象施展招式的动作和特效——是狂风呼啸或是火焰四射？你也可以为招式设定一个与角色联系的特殊背景，比如「被诅咒的禁忌招式」。

但无论其名称多么帅气，招式的攻击力都需遵守以下框架。

攻击类招式 · 3 个点数

攻击类招式有几个关键参数，你有 3 个点数，分别将其分配至不同参数上以改变攻击效果。

01 / 攻击力 Damage 1d6 + 智力加值（基础，不消耗点数） 提升为 1d8 消耗 1 点，1d10 消耗 2 点。你也可以选择降低为 1d4，同时获得 1 点点数用于分配至其他参数（即消耗点数为 -1）。
02 / 攻击范围 Area 基础 1 决定你能在以攻击落点为中心 n×n 的范围内造成攻击。单体攻击时默认为 0。注意：范围攻击会造成范围内除你以外所有角色（包括队友）受到伤害。
03 / 攻击距离 Range 基础 2 格（即一米） 决定你的最远攻击落点。每提升两格消耗 1 点点数。你也可以设定为 0（以自身为中心），同时获得 1 点点数。
04 / 攻击对象 Target 单体 0 点 / 群体 1 点 单体攻击无需消耗点数，群体攻击需消耗 1 点点数。单体攻击无需选择攻击范围。
05 / 冷却回合 Cooldown 标准 1 回合 冷却期间无法使用该技能。减少至 0 回合需消耗 1 点点数；设置为 2、3 回合可分别获得 1、2 点点数。
06 / 附加效果 Effect 1 点点数 / 项 三类可选：a. 附加伤害（三回合内每回合减少对手 1 点 PE）；b. 削弱对手（一场战斗内减少对方五项能力加值中任意一项 1 点）；c. 增强自己（一场战斗内增加自己五项能力加值中任意一项 1 点）。

变化类招式

变化类招式则有更多可玩性。持续长久的附加伤害？增减双方属性？甚至硬控对手回合、改变命中难度……展开你的想象，与队友讨论配合，最后获得主持人的许可即可。

设计时的建议

先想清楚这个招式在梦里「看起来是什么样」，再回头配参数。反过来做的人，最后往往得到一个数值很漂亮但没人记得住的技能。

异能的成长

升级时获得 1 点点数

当你的等级提升时，你的点数也会随之增加 1 点。你可以将其分配到伤害、攻击范围、攻击距离等参数上，也可以新增或提升附加效果，或为变化类招式获得更好的增益。也可以暂时保留，等到有需要时再分配。

点数碎片

完成一段很棒的 role play、或破解了隐藏的谜题，主持人可以给予你点数碎片作为奖励。当点数碎片积累到 5，就可以增加 1 点点数。

需要注意的是

仅专属心灵招式可以提升。同时，只有通过升级获得的点数才能用于异能成长——这一点在新成员中经常被搞混。

Combat & Harm

战斗与伤害

本规则采用双模式：现实中的战斗侧重叙事，采用非回合制的实时模式；梦境中的战斗侧重博弈，采用快节奏的卡牌战斗。绝大多数遭遇战发生于梦境之中。

MODE / A

梦中 · 卡牌式战斗

每回合开始先投掷先攻；随后所有人在不交流结果的前提下同时选定技能卡、攻击落点与移动点位，同时翻出后按先攻顺序结算。

快节奏高博弈性先攻 = 1d8 + 觉知
MODE / B

现实 · 演绎式战斗

不强调回合概念，将战斗融入叙事当中。鼓励利用场景与非玩家角色的互动进行自由战斗，减少非必要的战斗，强调战斗的逻辑和目的。

叙事优先可破局攻击 = 1d20 + 属性

现实中的伤害阈值

每个正常人类无论体魄有多么强健，在面对重大伤害事件时抵御能力都相差无几。现实中，每个人的伤害阈值统一为 3，并且不会随着等级提升。

状态伤害骰总值表现
健康< 4轻度伤害
轻度伤害4 — 10中度伤害
中度伤害10 — 16严重伤害
严重伤害≥ 16濒死
濒死即刻未得到立即救助将死亡

注：当目标已处于某一伤害状态时，上述阈值会相应下移，具体修正见《运作游戏》章节。梦境中伤害不会造成任何现实中的损伤。

惊吓值：梦境的属性

惊吓值并非角色的属性，而是梦境的属性，仅在梦境中出现。

当梦境主人在梦中受到伤害或惊吓时，惊吓值会减少。当惊吓值归零时，梦境主人会惊醒，梦境旅客也会被弹出梦境。

Initial Value 惊吓值初始为 20
受到攻击 按伤害骰结果扣减 攻击模式与梦境战斗相同：攻击检定决定能否命中，伤害骰决定造成的伤害值。只不过对梦境主人来说，伤害值等于惊吓值减少的值。
受到惊吓 按程度扣减 由主持人进行惊吓检定，难度依惊吓程度而定。若成功：程度大时减少 1d8，普通时减少 1d6，小时减少 1d4。

但恐惧不完全是坏事

当惊吓值越低，梦境便越有可能发生崩坏，产生强大的怪物，并且往坏的方向发展。但有时，噩梦可能可以搜集到全然不同的信息——恐惧会将人内心深处所畏惧的东西映射在梦境中。这也是为什么有些研究序列会主动申请「高压观测」。

Common Misconceptions

常见误解

以下每一条都来自真实的公众咨询记录。我们保留了原始问法。

✕「梦里时间比现实长。」Time in dreams

梦境中时间与现实中等同。之所以感觉更长，是因为梦境并非线形或连续，而是如电影场景一般经过剪辑和拼凑。两个小时的电影可能讲述了一年中发生的事，40 分钟的梦境也可能如同一生般丰富多彩。

✕「在梦里死了，现实里也会死。」Death in dreams

在梦境中伤害不会造成任何现实中的损伤。伤害只会扣减心灵能量（PE）；PE 归零时你会被强制弹出梦境，仅此而已。

✕「梦中出现的人都真实存在。」People in dreams

并非所有角色都于现实中存在。梦中人物的脸是模糊的，但绝大多数主要角色拥有清晰的特征——「清晰」不等于「真实」。

✕「梦里的物理规则是随机的。」Dream physics

梦境中的物理规则不一定与现实等同，但一定来源于现实。你可能在梦中太空漫步，或于深海中自由呼吸；同时，你所受的物理约束与梦境主人等同。

✕「只要不被发现，潜入就没问题。」Consent

未经本人或组织许可的潜梦是不合法的。「没被发现」不是免责条件，而是加重情节。

✕「梦境异能可以在现实中用。」Ability scope

梦境异能是仅能于梦境中使用的异能。现实中你只有物理攻击——正常拳头的攻击力为 1d4 加上你的身体素质加值。

✕「研究所在研究怎么造怪物。」Rumors

研究所的主要工作是观测、记录与解析。当惊吓值过低导致梦境崩坏时，梦中确实可能产生难缠的东西——但那属于需要处置的现场事故，不是我们的研究目标。
