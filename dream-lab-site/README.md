# 梦境研究所 · 官方网站（虚构设定站）

TRPG 作品《梦境旅客》中「梦境研究所」的官方网站，纯静态、零依赖。
直接双击 `index.html` 即可在浏览器中查看，也可以整体托管到 GitHub Pages / 任意静态空间。

## 视觉方向

参考维基百科条目页与极简展览信息页（如 [contemporary.minis.yoroll.ai](https://contemporary.minis.yoroll.ai/)）的排版逻辑：
**把页面当档案来排，而不是当宣传页来做。**

- **主色白**：页面底色 `#ffffff`，次级面 `#fbfcfe` / `#f4f6fa`，正文近黑 `#0a1020`，分隔线 `#e7ebf3`。
- **辅色光谱**：青 `#22b8e6`、紫 `#7b61ff`、品红 `#e4559e`、琥珀 `#f0a422`、青绿 `#23c08a`、珊瑚 `#f0654f`。
  每页用 `data-accent` 指定一个主题色，只用于导航当前项下划线、页头关键词、面板顶边与小型标记——不做渐变、不做发光。
- **首屏即档案**：文件头（编号 / 状态 / 版本）→ 机构名与一段说明性导语 → 关键术语表 →
  右侧 Wikipedia 式信息表与观测台读数。没有巨型标语，没有彩色艺术字，没有漂浮粒子。
- **信息密度优先**：等宽字体承载全部编号与数据，`1px` 细边框，直角为主（圆角统一为 3–4px），
  阴影几乎不用，表格化排版，页脚附免责与版本号。
- **克制的动效**：仅保留滚动进度、元素淡入与数字滚动，并完整尊重 `prefers-reduced-motion`。

```
│  └─ favicon.svg   站点图标
└─ tools/
   ├─ check.mjs       站点自检：链接、锚点、id 唯一性、资源、结构、表单元素
   ├─ freeze.mjs      生成动画冻结副本，供无头浏览器截图校验
   ├─ find-damage.mjs 只读扫描：定位非 UTF-8 / 损坏字节
   └─ repair-css.mjs  按字节偏移修复 style.css 中的损坏字符
```

## 交互脚本说明（`assets/app.js`）

零依赖，全部功能在原生 API 上实现：

- 移动端导航展开 / 收起，滚动进度条
- `IntersectionObserver` 元素入场动画与数字滚动器（尊重 `prefers-reduced-motion`）
- 页内锚点导航高亮（`about.html` / `admissions.html` / `dream-science.html` / `feedback.html`）
- **梦境六条机制卡片由 `MECHANISMS` 数据渲染**（`dream-science.html` 的 `#mechanisms`），便于后续增删条目
- 反馈表单：必填校验（含单选组与复选框）、邮箱格式校验、字数计数、受理编号生成与回执、本机邮箱记忆

> 反馈表单**不会向任何服务器发送数据**，递交结果仅在你的浏览器内生成受理编号与回执。
> `localStorage` 仅用于记住上次填写的邮箱，可在隐私模式下自动失效。

## 本地校验

```powershell
cd 'C:\Project\Dream Lab\dream-lab-site'
node tools/check.mjs
```

检查项：本地资源是否存在、页面内 `id` 是否唯一、80 个锚点是否全部可解析、
主导航链接与 `aria-current` 标记、每页的结构完整性（DOCTYPE / lang / viewport / title / description /
`<main>` 与 `<section>` 配对）、以及 `feedback.html` 的表单与回执元素是否齐全。

用无头浏览器截图校验时，请使用冻结副本（会关闭动画并写入终值，避免截到动画中间帧）：

```powershell
node tools/freeze.mjs --no-probe     # 输出 _frozen-*.html 到站点根目录
```

> 注意：`_frozen-*.html` 必须与 `assets/` 同级，否则相对路径的样式表加载不到，
> 截图会丢失全部样式。校验完成后可安全删除这些文件。
